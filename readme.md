# ¿Cómo ejecutar este código?


## Requisitos

- Node.js
- Git
- pnpm

---

## 1. Clonar el repositorio

```bash
git clone https://github.com/AnderOrtiz/POE.git

cd POE

git checkout ejercicios-clase3
```

---

## 2. Instalar las dependencias

```bash
pnpm install
```

> **¿No tienes pnpm?**
>
> Instálalo siguiendo la documentación oficial:
> https://pnpm.io/es/installation

---

## 3. Ejecutar un ejercicio

```bash
pnpm exec tsx src/<nombre_archivo>.ts
```

### Ejemplo

```bash
pnpm exec tsx src/ejercicio1.ts
```
